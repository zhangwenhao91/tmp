两个解决办法,任选:

方案 1:跳过该主机的证书校验(最快)

pip install "mlir-python-bindings==20260830+45c256b55" \
    --find-links https://llvm.github.io/eudsl \
    --trusted-host llvm.github.io

如果 --trusted-host 对 find-links 的下载不生效(有时只对 index 生效),用方案 2。

方案 2:curl 绕过证书校验下载 wheel,再本地安装(最稳)

a. 先看 eudsl 上有哪些 python3.11 可用的轮子:

curl -sk https://llvm.github.io/eudsl/ | grep -oE 'mlir_python_bindings[^"<]*\.whl' | grep -E 'cp311' | sort -u | tail -5

b. 下载对应版本(选列表里最新的那个文件名):

cd /tmp
curl -skO https://llvm.github.io/eudsl/mlir_python_bindings-20260830+45c256b55-cp311-cp311-manylinux_2_28_x86_64.whl

(文件名以上一步实际看到的为准,如果 20260830 这个确切版本没有 cp311 轮子,就下载列表里最新的 cp311 轮子。)

c. 本地安装并验证:

pip install /tmp/mlir_python_bindings-*.whl
python -c "import mlir; import mlir.dialects._ods_common; print('mlir ok')"

长期建议

这台服务器要常用 eudsl 源的话,把证书跳过写进 pip 配置,免得每次带参数:

pip config set global.trusted-host llvm.github.io

装好 mlir 后继续:

cd /home/zwh/tmp && python reduce_sum.py

把输出贴给我。如果 wheel 装完 import mlir 报别的错(比如缺 libmlir 运行库),也把报错发我。
