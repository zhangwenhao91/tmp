先试最简修正——把 github.com 也加进 trusted-host:

pip install "mlir-python-bindings==20260830+45c256b55" \
    --find-links https://llvm.github.io/eudsl \
    --trusted-host llvm.github.io \
    --trusted-host github.com

如果还报 SSL 错,就用 python 绕过证书验证直接下载 wheel(把下面整段粘贴执行):

cat > /tmp/dl_mlir.py <<'EOF'
import ssl, urllib.request
ctx = ssl._create_unverified_context()
url = ("https://github.com/llvm/eudsl/releases/download/mlir-python-bindings/"
       "mlir_python_bindings-20260830%2B45c256b55-cp311-cp311-manylinux_2_34_x86_64.whl")
data = urllib.request.urlopen(url, context=ctx).read()
open("/tmp/mlir_python_bindings.whl", "wb").write(data)
print("downloaded", len(data), "bytes")
EOF

python /tmp/dl_mlir.py

下载完成后本地安装并验证:

pip install /tmp/mlir_python_bindings.whl
python -c "import mlir; import mlir.dialects._ods_common; print('mlir ok')"
cd /home/zwh/tmp && python reduce_sum.py

两个可能的后续坑,先给你预防针:
- glibc 版本:这个 wheel 是 manylinux_2_34,要求 glibc ≥ 2.34。如果安装或 import 时报 GLIBC_2.34 not found,说明系统 glibc 太老,到时告诉我,我们找替代方案(比如让 pip 列出其它可用轮子)。
- 代理:如果 urllib 下载也卡住,多半是环境代理只对 pip 生效,到时候把 echo $HTTPS_PROXY $HTTP_PROXY 的输出发我。
