服务器缺的是 mlir-python-bindings 这个 python 包(tilelangir 的 dialect 绑定靠它,pyproject 里声明为依赖,但需要用官方源安装)。本机(同款仓库、正常跑通)装的是 `20260830+45c256b55`,从 https://llvm.github.io/eudsl 这个源装的——PyPI 上找不到它,必须带 --find-links。

在服务器上执行:

pip install mlir-python-bindings --find-links https://llvm.github.io/eudsl

如果直接装最新版跑起来有 MLIR API 兼容问题,就锁成与本机一致的版本(你的仓库是同期构建的,这个版本最贴合):

pip install "mlir-python-bindings==20260830+45c256b55" --find-links https://llvm.github.io/eudsl

然后验证:

python -c "import tilelang; print(tilelang.__file__)"
cd /home/zwh/tmp && python reduce_sum.py

两点预判:

- 装完 mlir 后如果又冒出别的 ModuleNotFoundError(比如 cloudpickle、ml_dtypes、psutil 等),说明当初装 tilelang 时跳过了依赖解析,把整份依赖补齐即可:

pip install -r /home/zwh/tilelang-tileir-ascend/requirements.txt --find-links https://llvm.github.io/eudsl

- torch 别乱装:你是昇腾环境,大概率已有 torch + torch_npu(CANN 配套),requirements 里即使列了 torch 也不要让 pip 去重装/降级,装依赖时加 --no-deps 手动补缺即可。
